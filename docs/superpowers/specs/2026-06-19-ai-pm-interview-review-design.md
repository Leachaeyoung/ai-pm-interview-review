# AI 产品经理面试复盘网站 — 设计文档

## 概述

一个面向 AI 产品经理的个人面试复盘工具，同时可作为产品作品展示给面试官。涵盖面试全流程：面试前的模拟准备、面试后的记录复盘、历史面经的时间线查阅、以及个人能力总结。

## 技术方案

| 维度 | 选择 | 理由 |
|------|------|------|
| 框架 | Next.js (App Router) | React 生态主流，支持 API Routes 做 AI 调用 |
| 内容存储 | Markdown / JSON 文件 + Git | 数据随代码部署，无需数据库，可版本控制 |
| 样式 | Tailwind CSS | 快速开发，响应式，现代化 |
| 部署 | Vercel | 免费，自动部署，支持自定义域名 |
| 动画 | Framer Motion | 时间线动画、页面过渡、模拟模式交互 |
| AI 能力 | 调用 LLM API（Claude / GPT） | 解析 JD、生成模拟题、辅助复盘建议 |

## 信息架构

```
导航栏: 面试前 | 面试后 | 复盘库 | 我的
```

### 页面一：面试前（模拟准备）

**目的：** 基于目标公司 JD 和历史面试数据，生成针对性模拟面试题，并提供类真实面试的模拟体验。

**功能：**
1. 上传/粘贴公司 JD 文本
2. AI 解析 JD → 提取岗位核心要求、关键词、业务方向
3. 生成 5-8 道模拟面试题（可重新生成）
4. 进入全屏模拟面试模式

**模拟题生成策略（优先级从高到低）：**
1. 复盘库中同公司的历史真实题目及变体
2. 复盘库中同岗位方向的历史题目
3. 用户标记的薄弱环节相关题目（加高权重）
4. 通用 AI 产品经理题库（覆盖：AI技术理解、数据分析与指标体系、产品设计与UX、业务思维与商业化、项目管理与跨团队协作、行业趋势与竞品分析）
5. 每次重新生成保证至少 30% 新题

**模拟面试模式交互：**
- 全屏沉浸式，顶部固定总计时 + 单题计时
- 计时颜色随剩余时间变化：绿 → 黄 → 红
- 单题流程：出题展示 → 60秒思考倒计时（可跳过）→ 回答录制（3-5分钟）
- 输入方式：语音转文字（录音按钮 + 波形动画）+ 键盘输入双模式
- 题目切换有过渡动画（卡片翻入）
- 完成后自动保存 Q&A 到「面试后」模块

### 页面二：面试后（记录与复盘）

**目的：** 录入真实面试的题目和自己的回答，逐题复盘反思。

**功能：**
1. 填选公司、岗位、日期、轮次
2. 逐题输入：面试题目 → 我的回答思路 → 复盘反思
3. 动态添加/删除题目
4. AI 辅助复盘（可选）：基于回答内容给出改进建议
5. 保存后进入复盘库

### 页面三：复盘库（时间线）

**目的：** 浏览所有历史面试记录，查阅复盘内容。

**功能：**
- 时间线式展示，按月份分组，竖线左侧日期 + 右侧卡片
- 每张卡片显示：公司、岗位、日期、轮次、题目数量、自评状态
- 点击卡片进入详情页（完整查看单次面试所有题目、回答、反思）
- 筛选：按公司、岗位、时间范围
- 搜索：关键词搜索题目内容

### 页面四：我的（能力总结）

**目的：** 汇总个人成长轨迹，提炼共性问题和改进方向。

**功能：**
- 能力雷达/自评：各维度打分（产品设计、数据分析、AI技术、业务思维、沟通表达等）
- 总体建议：手动维护的薄弱环节、提升方向
- 推荐学习资源：书单、课程、文章链接
- 可编辑

## 数据模型

```
Interview
├── id: string
├── company: string          # 公司名
├── position: string         # 岗位
├── date: string             # 面试日期
├── round: string            # 轮次（一面/二面/终面...）
├── questions: Array<{
│     question: string       # 面试题目
│     answer: string         # 我的回答思路
│     reflection: string     # 复盘反思
│ }>
└── createdAt: string

Profile
├── selfAssessment: Array<{
│     dimension: string      # 能力维度名
│     score: number          # 1-10 自评分
│ }>
├── weakPoints: string[]     # 薄弱环节列表
├── recommendations: string  # 总体建议（自由文本）
└── resources: Array<{
│     title: string
│     url: string
│     type: string           # book / course / article
│ }>
```

## 设计约束

- 桌面端优先（面试官在桌面浏览），同时保证移动端可读
- 纯文字 + 动画，不需要复杂图表库（SkillRadar 用 SVG/CSS 实现）
- AI 功能需 API Key，使用环境变量管理，不提交到仓库
- 模拟面试模式不在面试官浏览路径上，需要时可引导查看
